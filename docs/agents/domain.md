# Domain docs

DebtWise has a single domain context.

- [`GLOSSARY.md`](../../GLOSSARY.md) at the repo root defines the domain vocabulary. Code, API,
  issues and docs use its terms and avoid the ones it lists under _Avoid_.
- [`docs/adr/`](../adr/) holds the architecture decision records, numbered `NNNN-slug.md`. A change
  follows them until a newer ADR supersedes one.

There is no `GLOSSARY-MAP.md`. Add one only if the project splits into several contexts.
